# valk-guard-example

A realistic multi-language project used to demonstrate [Valk Guard](https://github.com/ValkDB/valk-guard) in a production-like repository.

## Goal

- Keep `main` branch clean (`valk-guard scan . --config .valk-guard.yaml --format json` returns `[]`).
- Open one demo PR per rule (`VG001`-`VG106`) to show review comments exactly where the issue is introduced.
- Use `VG001` as the first PR smoke test before expanding to other rules.

## Baseline Check

Run locally from this repo root:

```bash
valk-guard scan . --config .valk-guard.yaml --format json
```

Expected result on `main`:

```json
[]
```

## CI Version Strategy

Workflow install target is configured as:

```text
github.com/valkdb/valk-guard/cmd/valk-guard@latest
```

Rationale:

- This repository is a demo showcase; tracking latest keeps examples aligned with current built-in behavior.
- If you need strict reproducibility, pin a fixed tag in workflow `VALK_GUARD_INSTALL_REF`.

## Creating Demo PRs (one rule at a time)

Generate demo changes for one rule:

```bash
scripts/create-rule-demo.sh VG105
```

Supported: `VG001`-`VG008`, `VG101`-`VG106`.

Then open PR:

```bash
git checkout -b demo/vg105
git add demo/violations
git commit -m "demo: trigger VG105"
git push -u origin demo/vg105
```

### First PR Smoke Test (recommended)

```bash
git checkout -b demo/vg001
scripts/create-rule-demo.sh VG001
valk-guard scan . --config .valk-guard.yaml --format json
git add demo/violations
git commit -m "demo: trigger VG001"
git push -u origin demo/vg001
```
